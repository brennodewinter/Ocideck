# Document templates

New document offers a blank document, a recipe submission form, and CPE certificates.
The content language is explicitly Dutch or English, independently of the interface.
The recipe sources are the existing examples/forms/recept forms.

CPE issuance asks for course data once and a participant table. Each participant has
an individual net hour total and optional attendance exceptions. All participants
are validated before creating documents. Outputs are separate editable Markdown
documents; use the existing document export to create PDFs. The ISACA Netherlands
Chapter mark is a separate bundled image extracted from the supplied example ODT;
the provider logo and signature are optional independent image fields. No example
participant data or signature is bundled.
