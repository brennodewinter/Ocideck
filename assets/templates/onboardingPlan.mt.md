# Għan tal-onboarding

- Sib malajr madwar in-nies, is-sistemi u l-modi ta' kif taħdem
- Għanijiet ċari u li jistgħu jintlaħqu għal kull fażi
- Xi ħadd li jgħinek u lejh tista’ tirrikorri
- Minn shadowing għal kontribut indipendenti

# Mill-jum 1 sa jum 90

- Jum 1 :: Merħba :: Nies, post tax-xogħol u aċċess.
- Ġimgħa 1 :: Orjentazzjoni :: Tim, sistemi u l-ewwel kompiti.
- 30 jum :: Shadowing :: Tgħallem ix-xogħol u l-kuntest.
- 60 jum :: Indipendenti :: Aqbad u spiċċa l-kompiti lilek innifsek.
- 90 jum :: Kontribuzzjoni :: Kompletament aġġornat fir-rwol.
