# Debriefing / analiza po akciji
## Operacija · Datum in čas · Moderator · Udeleženci

---

# Namen in osnovna pravila

- Iz te operacije se učimo; ne iščemo krivca
- Najprej dejstva, nato mnenja: opišite, kaj ste videli in naredili
- Vsi lahko spregovorijo; rang ne igra nobene vloge
- Kar se tukaj deli, ostane znotraj ekipe
- Kratko in konkretno: zaključujemo z dogovorjenimi akcijami

---

# Kakšen je bil načrt

- Kakšna je bila naloga oziroma cilj operacije?
- Kakšen rezultat smo pričakovali vnaprej?
- Kdo je imel kakšno vlogo in nalogo?
- Kakšne predpostavke smo naredili vnaprej: …

# Zakaj je šlo tako

- Kaj je povzročilo razkorak med načrtom in realnostjo?
- Kaj smo takrat vedeli in česa ne?
- Katere okoliščine so igrale vlogo (viri, čas, informacije)?
- Opišite sistem, ne osebe: …

---

# Kaj je šlo dobro

- Kaj je delovalo in želimo obdržati?
- Katera odločitev ali vedenje je vplivalo?
- Kaj si zasluži pohvalo celotni ekipi?
- Kako to zagotovimo (postopek, sestanek, vaja)?

---

# Kaj bi lahko bilo boljše

- Kje so stvari tekle grobo ali drugače, kot je bilo predvideno?
- Kaj bi predali naslednji ekipi?
- Katera izboljšava prinese največ?
- Kaj lahko že jutri naredimo drugače: …
