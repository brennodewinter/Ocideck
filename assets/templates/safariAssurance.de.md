# SAFARI-Bewertung der digitalen Souveränität

---
# So funktioniert diese Arbeitsakte

- Legen Sie zunächst Umfang, Behauptung, gewünschte Stufen und den beabsichtigten Grad der Sicherheit fest.
- Füllen Sie jede Fragestellung mit der Feststellung, einer nachvollziehbaren Quellenreferenz und dem Beweisniveau aus.
- Behandeln Sie fehlende oder verweigerte Beweise als eine Feststellung mit Beweisniveau 0.
- Wenden Sie die sechs Bewertungskriterien an, bevor Sie das Niveau für jedes SOV-Ziel festlegen.
- Formulieren Sie das Assurance-Urteil erst, nachdem Qualitätskontrolle und Ereignisse nach dem Basisdatum bewertet wurden.

# Bindende Bewertungskriterien

| Regel | Konsequenz für das Urteil |
| --- | --- |
| 0 · Rechtmäßigkeit | Ein Rechtmäßigkeitrisiko macht das betreffende Ziel immer eine Lücke; empfehlen Sie eine rechtliche Prüfung. |
| 1 · Kritische Fragen | Beweisniveau 0 bei einer kritischen Frage begrenzt das Ziel auf höchstens Level 1. |
| 2 · Beweis trägt das Level | Beweis unter dem Minimum einer Frage zählt als 0. Das Zielbeweis ist das niedrigste Beweis auf kritische Fragen; Level 2, 3 und 4 erfordern dafür mindestens dasselbe Beweisniveau. |
| 3 · Schwächste Verknüpfung | Das SEAL-Gesamtlevel ist das niedrigste festgelegte Level der Kernziele. |
| 4 · Arbeitsrecht | Bei durchsetzbaren ausländischer Zugriff schützt nur die vollständige technische Route; diese ändert SOV-2 und das SEAL-Gesamt nicht. Ein Dienst, der lesbare Daten verarbeiten muss, hat diese Route nicht. |
| 5 · Technische Route | Bei durchsetzbaren ausländischer Zugriff schützt nur die vollständige technische Route; diese ändert SOV-2 und das SEAL-Gesamt nicht. |
