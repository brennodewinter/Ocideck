# 3. Execução

---

# Atividades de execução

- Assuma a violação como ponto de partida.
- Qualificação com CVSS 4.0 (pontuação + string vetorial).
- Evidência: hashes de material probatório (SHA1/SHA-256).
- Validação dos resultados da verificação (sem confiança cega no scanner).
- Documentando os caminhos de acesso usados.
