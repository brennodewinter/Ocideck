# Ρόλος του buddy ή μέντορα

- Να είναι ένα σταθερό, εύκολα προσβάσιμο σημείο επικοινωνίας
- Να εξηγεί τους άγραφους κανόνες και τις συνήθειες
- Να συμβουλεύει χωρίς να αναλαμβάνει τη δουλειά
- Να προσέχει όταν κάτι δεν πάει καλά

---

# Οι στόχοι του νέου

- Τι θέλετε να μάθετε τους πρώτους μήνες;
- Πού θέλετε να αυτονομηθείτε γρήγορα;
- Τι ακόμα σας φαίνεται απαιτητικό ή ασαφές;
- Πώς προτιμάτε να λαμβάνετε καθοδήγηση;
