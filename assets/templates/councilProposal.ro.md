# Consiliu / propunere executivă
## Subiect · Portofoliu · Număr de înregistrare · Autor

---

# Fundal

- De ce este această propunere pe masă acum?
- Ce hotărâre a consiliului, îndatorire statutară sau semnal o precede?
- Ce se întâmplă dacă consiliul nu decide?
- Cadre relevante (acord de coaliție, statut, document de politică): …

---

# Rezultatul scontat

- Ce rezultat societal dorim să obținem?
- Se observa pentru cine și cum o măsurăm?
- Cum se leagă acest lucru cu politica existentă?

---

# Puncte de decizie

- 1. Consiliul hotărăște: …
- 2. Consiliul hotărăște: …
- 3. Să pună la dispoziție bugetul necesar și să modifice bugetul în consecință
- 4. Să instruiască executivul să raporteze progresul înapoi către consiliu

---

# Argumente

- 1.1 Propunerea contribuie la rezultatul scontat deoarece...
- 1.2 Se aliniază cadrului adoptat: …
- 2.1 Au fost cântărite alternative; această propunere are cel mai bun punctaj pe...
- 3.1 Finanțarea este acoperită structural în...

---

# Avertismente și riscuri

- 1.1 Rezultatul depinde parțial de terți: …
- 1.2 Sprijinul nu poate fi considerat de la sine înțeles printre...
- 2.1 Risc financiar în caz de eșecuri: …
- 2.2 Risc juridic sau de livrare: …
- Măsuri de atenuare per risc: …

# Participare și sprijin

- Cine a fost implicat (rezidenți, întreprinderi, consilii consultative, parteneri)?
- Ce s-a adunat și ce s-a făcut cu el?
- Unde se abate propunerea de la intrare și de ce?
- Cum vor fi informați cei implicați cu privire la decizie?

# Următorii pași și planificare

- Săptămâna 1 :: Comitetul :: Discuție deliberativă și întrebări tehnice.
- Săptămâna 3 :: Consiliul :: Şedinţa de luare a deciziilor; votează punctele de decizie.

- Q2 :: Livrare :: Începutul livrării și primul raport de progres către consiliu.
