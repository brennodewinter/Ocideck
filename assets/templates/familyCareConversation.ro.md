# Despre ce este această conversație

- Ce se întâmplă (decizii de tratament, îngrijire, mutare, moștenire)?
- Care este motivul direct pentru a veni împreună acum?
- Ce ar trebui să ofere această conversație?
- Ce nu trebuie decis astăzi?

# Reguli de bază pentru conversație

- Toată lumea poate să vorbească, inclusiv cine este tăcut
- Mai întâi înțelegeți, apoi răspundeți
- Dorințele persoanei vizate cântăresc cel mai mult
- O decizie nu trebuie luată astăzi
- Emoțiile sunt permise; conversația continuă
