# SIPOC-Prozessübersicht
## Lieferant · Input · Prozess · Output · Kunde

---

# Was bildet SIPOC ab?

- **Lieferant:** stellt die Informationen oder Ressourcen bereit, die der Prozess benötigt.
- **Eingabe:** Daten, Materialien oder andere für den Prozess erforderliche Bedingungen.
- **Prozess:** 4 bis 7 übergeordnete Aktivitäten, die die Eingabe transformieren.
- **Ausgabe:** das Produkt, die Dienstleistung oder die Informationen, die der Prozess produziert.
- **Kunde:** der interne oder externe Empfänger der Ausgabe.

# Vervollständigen Sie es von rechts nach links

1. Set clear start and end points for the process.
2. Name the customers who depend on the result.
3. Describe the outputs they receive.
4. Summarise the process in 4 to 7 high-level activities.
5. Determine which inputs those activities need.
6. Link each input to the supplier who makes it available.
