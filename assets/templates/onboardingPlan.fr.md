# Objectif de l'intégration

- Trouvez rapidement votre chemin parmi les personnes, les systèmes et les méthodes de travail
- Objectifs clairs et réalisables par phase
- Quelqu'un qui vous aide et vers qui vous pouvez vous tourner
- De l’observation à la contribution indépendante

---

<!-- _class: timeline -->

# Du jour 1 au jour 90

- Jour 1 :: Accueil :: Personnes, lieu de travail et accès.
- Semaine 1 :: Orientation :: Équipe, systèmes et premières tâches.
- 30 jours :: Shadowing :: Apprendre l'œuvre et le contexte.
- 60 jours :: Indépendant :: Récupérez et terminez les tâches vous-même.
- 90 jours :: Contribuer :: Parfaitement à jour dans le rôle.
