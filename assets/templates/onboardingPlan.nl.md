# Doel van het inwerken

# Van dag 1 tot dag 90

- Dag 1 :: Welkom :: Mensen, werkplek en toegang.
- Week 1 :: Wegwijs :: Team, systemen en eerste taken.
- 30 dagen :: Meelopen :: Het werk en de context leren kennen.
- 60 dagen :: Zelfstandig :: Zelf taken oppakken en afronden.
- 90 dagen :: Bijdragen :: Volwaardig meedraaien in de rol.
