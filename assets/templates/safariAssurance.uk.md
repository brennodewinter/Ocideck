# Оцінювання SAFARI цифрового суверенітету

---
# Як ви використовуєте цей робочий аркуш

- Спочатку визначте обсяг, твердження, бажані рівні та бажаний ступінь впевненості.
- За кожне запитання щодо виявлення задокументуйте виявлення, відстежуване посилання на джерело та рівень доказу.
- Обробляйте відсутні або відхилені докази як виявлення з рівнем доказу 0.
- Застосовуйте шість правил оцінювання перед визначенням рівня для кожної мети SOV.
- Сформулюйте висновок про запевнення та події після дати огляду лише після оцінки контролю якості та подій після дати огляду.

# Рівні доказів

| Рівень | Ім'я | Додаток |
| --- | --- | --- |
| 0 | Немає доказів | Немає обґрунтувань, або докази відсутні або спростовані |
| 1 | Заява | Усна або письмова заява без додаткових обґрунтувань |

| 4 | Незалежні докази | Зібрано або підтверджено незалежною перевіряючою стороною |

# Прийняті правила оцінювання

| Правило | Наслідки для висновку |
| --- | --- |
| 0 · Правомірність | Правомірний ризик робить відповідну мету завжди прогалиною; рекомендуйте юридичну перевірку. |
| 1 · Критичні запитання | Доказ рівня 0 для критичного запитання обмежує мету до рівня 1. |
| 2 · Доказ підтримує рівень | Доказ нижче мінімального рівня запитання вважається 0. Мета доказ є найнижчим рівнем доказів для критичних запитань; рівень 2, 3 і 4 вимагають, щоб він міг мінімум мати той самий рівень доказів. |
| 3 · Найслабший зв’язок | Рівень SEAL загалом є найнижчим встановленим рівнем для ключових цілей. |
| 4 · Законний порядок | Якщо застосовний іноземний контроль та відсутня незалежна правова процедура або можливість повідомлення, 2.3, 2.5 і 2.6 вважаються доказами 0; SOV-2 не більше 1, а SOV-1 також, якщо тут знаходиться контроль. |
| 5 · Технічний маршрут | Якщо застосовний іноземний контроль захищає лише повний технічний маршрут; це не змінює SOV-2 і SEAL загалом. Послуга, яка повинна обробляти читані дані, не має цього маршруту. |
