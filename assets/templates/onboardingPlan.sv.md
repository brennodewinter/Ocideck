# Introduktionsplan (30-60-90 dagar)
## Nyanställning · Roll · Guide · Startdatum

---

# Syftet med onboarding

- Hitta snabbt runt människor, system och sätt att arbeta
- Tydliga, uppnåeliga mål per fas
- Någon som hjälper dig och som du kan vända dig till
- Från skuggning till att bidra självständigt

---

<!-- _class: timeline -->

# Från dag 1 till dag 90

- Dag 1 :: Välkommen :: Människor, arbetsplats och tillgång.
- Vecka 1 :: Orientering :: Team, system och första uppgifter.
- 30 dagar :: Skuggning :: Lär dig arbetet och sammanhanget.
- 60 dagar :: Oberoende :: Plocka upp och slutför uppgifter själv.
- 90 dagar :: Bidrar :: Fullt upp i farten i rollen.
