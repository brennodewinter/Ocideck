# Tervetuloa ja tämän illan tarkoitus

- Kiva, että olet täällä: tänä iltana kuulet, miltä tämä vuosi näyttää
- Mitä arvostamme luokkahuoneessa ja miksi
- Teemme sopimukset ja mitä voit odottaa meiltä
- Tilaa kysymyksillesi illan päätteeksi

<!-- _class: timeline -->

# Vuosi yhdellä silmäyksellä

- Jakso 1 :: Aloitus :: Tutustuminen, rytmin rakentaminen ja ensimmäiset testit.
- Periodi 2 :: Syventäminen :: Ydinaiheiden läpikäyminen ja ensimmäinen raportti.
- Jakso 3 :: Kasvu :: Suuremmat toimeksiannot, yhteistyö ja edistymisneuvottelut.
- Jakso 4 :: Päätös :: Viimeiset testit, katse taaksepäin ja askel ensi vuoteen.
