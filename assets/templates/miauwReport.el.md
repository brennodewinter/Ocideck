# 3. Εκτέλεση

---

# Δραστηριότητες εκτέλεσης

- Θεώρηση παραβίασης ως σημείο εκκίνησης.
- Πιστοποίηση με CVSS 4.0 (σκορ + vector string).
- Αποδεικτικά στοιχεία: hashes του αποδεικτικού υλικού (SHA1/SHA-256).
- Επικύρωση αποτελεσμάτων σάρωσης (χωρίς τυφλή εμπιστοσύνη στον scanner).
- Τεκμηρίωση των διαδρομών πρόσβασης που χρησιμοποιήθηκαν.
