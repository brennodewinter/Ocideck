# Σχέδιο ενσωμάτωσης (30-60-90 ημέρες)
## Νέος υπάλληλος · Ρόλος · Οδηγός · Ημερομηνία έναρξης

---

# Σκοπός της ενσωμάτωσης

- Βρείτε γρήγορα τον δρόμο σας ανάμεσα σε ανθρώπους, συστήματα και τρόπους εργασίας
- Σαφείς, εφικτοί στόχοι ανά φάση
- Κάποιος που σας βοηθά και στον οποίο μπορείτε να απευθύνεστε
- Από παρακολούθηση σε ανεξάρτητη συνεισφορά

---

<!-- _class: timeline -->

# Από ημέρα 1 έως ημέρα 90

- Ημέρα 1 :: Καλωσόρισμα :: Άνθρωποι, χώρος εργασίας και πρόσβαση.
- Εβδομάδα 1 :: Προσανατολισμός :: Ομάδα, συστήματα και πρώτες εργασίες.
- 30 ημέρες :: Παρακολούθηση :: Μάθετε την εργασία και το πλαίσιο.
- 60 ημέρες :: Ανεξάρτητος/η :: Αναλάβετε και ολοκληρώστε μόνοι/ες σας εργασίες.
- 90 ημέρες :: Συνεισφορά :: Πλήρως ενταγμένοι/ες στον ρόλο.
