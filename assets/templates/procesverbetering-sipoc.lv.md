# SIPOC procesa pārskats
## Piegādātājs · Ievade · Process · Izvade · Klients

---

# Ko SIPOC kartē?

- **Piegādātājs:** nodrošina procesam nepieciešamo informāciju vai resursus.
- **Ievade:** dati, materiāli vai citi procesam nepieciešamie nosacījumi.
- **Process:** 4–7 augsta līmeņa aktivitātes, kas pārveido ievadi.
- **Izvade:** procesa radītais produkts, pakalpojums vai informācija.
- **Klients:** izvades iekšējais vai ārējais saņēmējs.

# Aizpildiet to no labās uz kreiso pusi

1. Set clear start and end points for the process.
2. Name the customers who depend on the result.
3. Describe the outputs they receive.
4. Summarise the process in 4 to 7 high-level activities.
5. Determine which inputs those activities need.
6. Link each input to the supplier who makes it available.
