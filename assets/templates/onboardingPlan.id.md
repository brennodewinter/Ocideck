# Rencana orientasi (30-60-90 hari)
## Karyawan baru · Peran · Panduan · Tanggal mulai

---

# Tujuan orientasi

- Temukan cara Anda mengatasi orang, sistem, dan cara kerja dengan cepat
- Tujuan yang jelas dan dapat dicapai per fase
- Seseorang yang membantu Anda dan kepada siapa Anda dapat berpaling
- Mulai dari membayangi hingga berkontribusi secara mandiri

---

<!-- _class: timeline -->

# Dari hari ke-1 hingga hari ke-90

- Hari 1 :: Selamat datang :: Orang, tempat kerja, dan akses.
- Minggu 1 :: Orientasi :: Tim, sistem dan tugas pertama.
- 30 hari :: Shadowing :: Pelajari karya dan konteksnya.
- 60 hari :: Mandiri :: Ambil dan selesaikan tugas sendiri.
- 90 hari :: Berkontribusi :: Sepenuhnya mempercepat peran tersebut.
