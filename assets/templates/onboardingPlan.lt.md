# Priėmimo tikslas

- Greitai orientuokite žmones, sistemas ir darbo būdus
- Aiškūs, pasiekiami kiekvieno etapo tikslai
- Žmogus, kuris tau padeda ir į kurį gali kreiptis
- Nuo šešėlio iki savarankiško prisidėjimo

---

<!-- _class: timeline -->

# Nuo 1 dienos iki 90 dienos

- 1 diena :: Sveiki atvykę :: Žmonės, darbo vieta ir prieiga.
- 1 savaitė :: Orientacija :: Komanda, sistemos ir pirmosios užduotys.
- 30 dienų :: Shadowing :: Išmokite darbą ir kontekstą.
- 60 dienų :: Nepriklausomas :: Pasiimk ir baik užduotis pats.
- 90 dienų :: Prisideda :: Visiškai įsibėgėjo vaidmenyje.
