# Onboarding-plan (30-60-90 dage)
## Nyansættelse · Rolle · Vejleder · Startdato

---

# Formål med onboarding

- Find hurtigt rundt i mennesker, systemer og måder at arbejde på
- Klare, opnåelige mål pr. fase
- En, der hjælper dig, og som du kan henvende dig til
- Fra skygge til at bidrage selvstændigt

---

<!-- _class: timeline -->

# Fra dag 1 til dag 90

- Dag 1 :: Velkommen :: Mennesker, arbejdsplads og adgang.
- Uge 1 :: Orientering :: Team, systemer og første opgaver.
- 30 dage :: Shadowing :: Lær arbejdet og sammenhængen.
- 60 dage :: Uafhængig :: Saml og afslut opgaver selv.
- 90 dage :: Bidrager :: Fuldstændig på farten i rollen.
