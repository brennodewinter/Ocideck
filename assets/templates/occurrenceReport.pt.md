# Apenas cultura: informe para aprender

- Reportamos para aprender, não para punir
- Os fatos vêm primeiro, não a questão da culpa
- Um relato honesto de um erro honesto não é usado contra você
- Somente dolo ou negligência grave ultrapassa os limites

# O que mantém isso livre de culpa

- Um erro honesto em uma situação complexa é humano
- Procuramos a causa no sistema, não na pessoa
- A linha é risco deliberado, intenção ou negligência grave
- O relatório permanece dentro da confidencialidade acordada
