# De quoi parle cette conversation

- Que se passe-t-il (décisions de traitement, soins, déménagement, héritage) ?
- Quelle est la raison directe de vous réunir maintenant ?
- Que devrait apporter cette conversation ?
- Qu’est-ce qui n’a pas besoin d’être décidé aujourd’hui ?

# Règles de base pour la conversation

- Tout le monde peut parler, y compris ceux qui se taisent
- Comprenez d’abord, puis répondez
- Les souhaits de la personne concernée pèsent le plus lourd
- Il n'est pas nécessaire de prendre une décision aujourd'hui
- Les émotions sont autorisées ; la conversation continue
