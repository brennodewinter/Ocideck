# Les quatre étapes du plan de passage (APEM)

- **Appraisal:** rassemble toutes les informations pour le voyage
- **Planning:** définit l'itinéraire, les waypoints et les zones interdites
- **Execution:** effectue le voyage comme prévu
- **Monitoring:** surveille la position et l'écart en continu
- Autour de lui : Bridge Resource Management – travailler ensemble sur le pont
