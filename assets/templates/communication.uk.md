# Хронометраж і моменти публікації

- Тиждень 1 :: Внутрішня підготовка :: Тексти та запитання та відповіді готові.
- Тиждень 2 :: Узгодження :: Партнери та прес-секретарі поінформовані.
- Тиждень 3 :: Публікація
- Тиждень 4 :: Подальше спостереження та моніторинг
