# Propósito y reglas de privacidad

- Juntos una imagen y un próximo paso para este caso
- El caso está anonimizado: sin nombres, direcciones ni otros datos identificativos
- Lo que se discute aquí se queda en el equipo
- ¿Inseguro de si algo es identificable? El escáner de privacidad integrado lee esta presentación
