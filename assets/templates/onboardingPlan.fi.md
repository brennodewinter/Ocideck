# Perehdytyksen tarkoitus

- Tutustu nopeasti ihmisten, järjestelmien ja työtapojen ympärille
- Selkeät, saavutettavissa olevat tavoitteet vaihetta kohti
- Joku, joka auttaa sinua ja jonka puoleen voit kääntyä
- Varjosta itsenäiseen osallistumiseen

<!-- _class: timeline -->

# Päivästä 1 päivään 90

- Päivä 1 :: Tervetuloa :: Ihmiset, työpaikka ja pääsy.
- Viikko 1 :: Orientaatio :: Tiimi, järjestelmät ja ensimmäiset tehtävät.
- 30 päivää :: Varjostus :: Opi työ ja konteksti.
- 60 päivää :: Itsenäinen :: Poimi ja suorita tehtävät itse.
- 90 päivää :: Osallistuminen :: Täysin vauhdissa roolissa.
