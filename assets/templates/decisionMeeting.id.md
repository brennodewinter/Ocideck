# Bagaimana pertemuan ini berjalan

- Setiap agenda memiliki satu tujuan: untuk menginformasikan, mendiskusikan atau memutuskan
- Pertama faktanya, lalu pandangannya, baru kemudian keputusannya
- Keputusan dan tindakan dicatat di tempat, bersama pemiliknya
- Keberatan diajukan dalam rapat, bukan setelahnya
