# İlk katılım amacı

- İnsanlar, sistemler ve çalışma yöntemleri arasında yolunuzu hızla bulun
- Aşama başına net, ulaşılabilir hedefler
- Size yardım eden ve başvurabileceğiniz biri
- Gölgelemeden bağımsız katkıda bulunmaya

# 1. günden 90. güne kadar

- 1. Gün :: Hoş Geldiniz :: İnsanlar, işyeri ve erişim.

- 30 gün :: Gölgelendirme :: Çalışmayı ve içeriğini öğrenin.
- 60 gün :: Bağımsız :: Görevleri kendiniz toplayın ve tamamlayın.
- 90 gün :: Katkıda bulunmak :: Rolde tamamen hızlanmak.
