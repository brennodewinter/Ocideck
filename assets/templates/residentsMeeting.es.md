# Qué pasa con su respuesta

- Esta noche :: Recopilar :: Todas las preguntas y reacciones se registran.
- Semana 1 :: Agrupar :: Las reacciones se agrupan y responden en un informe.
- Semana 6 :: Devolver :: Escuchan qué se hizo con su input y por qué.
- Después :: Decidir y entregar :: La decisión se toma y comienza la entrega.
