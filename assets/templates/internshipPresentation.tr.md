# Aşamalı yaklaşım

- 1. Hafta :: Keşfet :: Şirketi, departmanı ve görevi tanıma.
- 3. Hafta :: Araştırma :: Ödev ve toplama gereksinimlerinin ardındaki soruyu derinlemesine incelemek.
- 6. Hafta :: Yürütme :: Yol boyunca inşaat, test etme ve süpervizörle kontrol etme.
- 10. Hafta :: Bitiş :: Raporun teslim edilmesi, teslim edilmesi ve tamamlanması.
