# Seara părinților/seară de informare
## Clasă sau grup · An școlar · Locație

---

# Bun venit și scopul acestei seri

- Mă bucur că ești aici: în seara asta vei auzi cum arată anul acesta
- Ce prețuim în clasă și de ce
- Acordurile pe care le facem și la ce vă puteți aștepta de la noi
- Spațiu pentru întrebările tale la sfârșitul serii

---

<!-- _class: timeline -->

# Anul dintr-o privire

- Perioada 1 :: Start :: Cunoașterea, construirea unui ritm și primele teste.
- Perioada 2 :: Aprofundare :: Lucrarea subiectelor de bază și a primului raport.
- Perioada 3 :: Creștere :: Misiuni mai mari, discuții de colaborare și progres.
- Perioada 4 :: Încheiere :: Teste finale, privire în urmă și pasul către anul viitor.
