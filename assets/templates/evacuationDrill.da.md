# Formål med øvelsen

- Test om evakueringen forløber problemfrit og til tiden
- Responders og personale kender deres opgave
- Ruter, signaler og samlingsstedsarbejde
- Saml forbedringer uden at bebrejde nogen

# Scenarie

- Hvad er udløseren (brand, gaslækage, trussel)?
- Hvor starter det, og hvordan udvikler det sig?
- Hvilke antagelser gælder for denne øvelse?
- Hvad øver vi bevidst og ikke?
