# Інтерактивна вікторина

---

# Про цю вікторину

- Три запитання, три формати запитань
- Спочатку дайте відповідь самі, а потім обговоримо разом
- Зрозумів неправильно? Саме так ми вчимося

---

<!-- _class: question -->

# Питання 1: множинний вибір

```question
{
  "kind": "multipleChoice",
  "prompt": "Замініть це власним запитанням із варіантами відповідей.",
  "optionCount": 4,
  "timeLimitSeconds": 0,
  "onWrong": "retry",
  "answers": [
    {
      "text": "Правильна відповідь",
      "correct": true
    },
    {
      "text": "Неправильна відповідь",
      "correct": false
    },
    {
      "text": "Ще одна неправильна відповідь",
      "correct": false
    },
    {
      "text": "І ще одна неправильна відповідь",
      "correct": false
    }
  ]
}
```

---

# Пояснення відповіді

- Чому це правильна відповідь: …
- Поширена помилка: …
