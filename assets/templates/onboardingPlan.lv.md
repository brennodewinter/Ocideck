# Uzņemšanas plāns (30–60–90 dienas)
## Jauns darbā · Loma · Ceļvedis · Sākuma datums

---

# Uzņemšanas mērķis

- Ātri orientējieties uz cilvēkiem, sistēmām un darba veidiem
- Skaidri, sasniedzami mērķi katrā fāzē
- Kāds, kurš tev palīdz un pie kā tu vari vērsties
- No ēnošanas līdz patstāvīgam ieguldījumam

---

<!-- _class: timeline -->

# No 1. līdz 90. dienai

- 1. diena :: Laipni lūdzam :: Cilvēki, darba vieta un piekļuve.
- 1. nedēļa :: Orientēšanās :: Komanda, sistēmas un pirmie uzdevumi.
- 30 dienas :: Ēnošana :: Apgūstiet darbu un kontekstu.
- 60 dienas :: Neatkarīgs :: Paņemiet un pabeidziet uzdevumus pats.
- 90 dienas :: Ieguldījums :: Pilnībā līdzi lomai.
