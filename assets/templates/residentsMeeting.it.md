# Cosa succede con la tua risposta?

- Stasera :: Raccogli :: Tutte le domande e le reazioni vengono registrate.
- Settimana 1 :: Pacchetto :: Le reazioni vengono raggruppate e ricevono risposta in un rapporto di risposta.
- Settimana 6 :: Rapporto :: Senti cosa è stato fatto con il tuo contributo e perché.
- Successivamente :: Decidi e consegna :: La decisione viene presa e la consegna inizia.
