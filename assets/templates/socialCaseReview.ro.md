# Scopul și regulile de confidențialitate

- Împreună o imagine și un pas următor pentru acest caz
- Cazul este anonimizat: fără nume, adrese sau alte detalii de identificare
- Ceea ce se discută aici rămâne în echipă
- Nu sunteți sigur dacă ceva este identificabil? Scanarea de confidențialitate încorporată citește acest pachet

# Întrebarea pentru echipă

- Care este întrebarea concretă a prezentatorului?
- Este vorba de sfaturi, de gândire sau de o decizie?
- Ce cunoștințe sau conexiuni poate oferi echipa?
- Ce părere are rezidentul sau familia despre direcția?
