# Proposta lill-kunsill / lill-eżekuttiv
## Suġġett · Portafoll · Numru ta’ reġistrazzjoni · Awtur

---

# Sfond

- Għaliex din il-proposta qiegħda fuq il-mejda issa?
- Liema deċiżjoni tal-kunsill, dmir statutorju jew sinjal jippreċediha?
- X'jiġri jekk il-kunsill ma jiddeċidix?
- Oqfsa rilevanti (ftehim ta’ koalizzjoni, bylaw, dokument ta’ politika): …

---

# Riżultat maħsub

- Liema riżultat tas-soċjetà rridu niksbu?
- Innota għal min, u kif inkejlu?
- Dan kif jirrelata mal-politika eżistenti?

---

# Punti ta' deċiżjoni

- 1. Il-kunsill jiddeċiedi li: …
- 2. Il-kunsill jiddeċiedi li: …

- 4. Li jagħti struzzjonijiet lill-eżekuttiv biex jirrapporta l-progress lura lill-kunsill

---

# Argumenti

- 1.1 Il-proposta tikkontribwixxi għall-eżitu maħsub għaliex...
- 1.2 Hija tallinja mal-qafas adottat: …
- 2.1 L-alternattivi ġew miżuna; din il-proposta tikseb l-aħjar fuq...
- 3.1 Il-finanzjament huwa strutturalment kopert fi ...

---

# Caveats u riskji

- 1.2 L-appoġġ ma jistax jitqies bħala fatt fost...
- 2.1 Riskju finanzjarju f'każ ta' intoppi: …
- 2.2 Riskju legali jew tal-kunsinna: …

# Il-passi li jmiss u l-ippjanar

- Ġimgħa 1 :: Kumitat :: Diskussjoni deliberattiva u mistoqsijiet tekniċi.
- Ġimgħa 3 :: Kunsill :: Laqgħa tat-teħid tad-deċiżjonijiet; jivvota fuq il-punti ta' deċiżjoni.

- Q2 :: Kunsinna :: Bidu tal-kunsinna u l-ewwel rapport ta’ progress lill-kunsill.
