# Що станеться з вашою відповіддю

- Сьогодні ввечері :: Зберіть :: Усі запитання та реакції записуються.
- Тиждень 1 :: Збірка :: Реакції групуються, а відповіді на них надаються у звіті про відповіді.
- Тиждень 6 :: Звіт :: Ви чуєте, що було зроблено з вашим внеском і чому.
- Після цього :: Вирішіть і доставте :: Рішення прийнято і доставка починається.
