# Forbhreathnú ar phróiseas SIPOC
## Soláthraí · Ionchur · Próiseas · Aschur · Custaiméir

---

# Cad a dhéanann SIPOC mapáil?

- **Soláthraí:** a sholáthraíonn an fhaisnéis nó na hacmhainní a theastaíonn ón bpróiseas.
- **Ionchur:** sonraí, ábhair nó coinníollacha eile a éilíonn an próiseas.
- **Próiseas:** 4 go 7 ngníomhaíocht ardleibhéil a athraíonn an t-ionchur.
- **Aschur:** an táirge, an tseirbhís nó an fhaisnéis a tháirgeann an próiseas.
- **Custaiméir:** faighteoir inmheánach nó seachtrach an aschuir.

# Comhlánaigh é ó dheis go clé

1. Set clear start and end points for the process.
2. Name the customers who depend on the result.
3. Describe the outputs they receive.
4. Summarise the process in 4 to 7 high-level activities.
5. Determine which inputs those activities need.
6. Link each input to the supplier who makes it available.
