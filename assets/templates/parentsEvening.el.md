# Η χρονιά με μια ματιά

- Περίοδος 1 :: Έναρξη :: Γνωριζόμαστε, χτίζουμε έναν ρυθμό και οι πρώτες δοκιμασίες.
- Περίοδος 2 :: Εμβάθυνση :: Εργαζόμαστε στα βασικά μαθήματα και η πρώτη έκθεση.
- Περίοδος 3 :: Ανάπτυξη :: Μεγαλύτερες εργασίες, συνεργασία και συζητήσεις προόδου.
- Περίοδος 4 :: Ολοκλήρωση :: Τελικές δοκιμασίες, ανασκόπηση και το βήμα για του χρόνου.
