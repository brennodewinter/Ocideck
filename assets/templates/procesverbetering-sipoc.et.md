# SIPOC protsessi ülevaade
## Tarnija · Sisend · Protsess · Väljund · Klient

---

# Mida SIPOC kaardistab?

- **Tarnija:** pakub protsessi jaoks vajalikku teavet või ressursse.
- **Sisend:** andmed, materjalid või muud protsessi jaoks vajalikud tingimused.
- **Protsess:** 4–7 kõrgetasemelist tegevust, mis muudavad sisendit.
- **Väljund:** toode, teenus või teave, mida protsessi toodab.
- **Klient:** väljundi sisemine või väline saaja.

# Täitke see paremalt vasakule

1. Set clear start and end points for the process.
2. Name the customers who depend on the result.
3. Describe the outputs they receive.
4. Summarise the process in 4 to 7 high-level activities.
5. Determine which inputs those activities need.
6. Link each input to the supplier who makes it available.
