- Kaj se zgodi z vašim vnosom?

# Kaj se zgodi z vašim odgovorom

- 6. teden :: Poročilo :: Slišite, kaj je bilo narejeno z vašim prispevkom in zakaj.
- Po tem :: Odločite se in izvedite :: Odločitev je sprejeta in dostava se začne.
