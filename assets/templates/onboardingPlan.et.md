# Sissetuleku eesmärk

- Leia kiiresti orienteeruda inimestes, süsteemides ja tööviisides
- Selged, saavutatavad eesmärgid faasi kohta
- Keegi, kes sind aitab ja kelle poole saad pöörduda
- Varjutamisest iseseisva panustamiseni

---

# 1. päevast 90. päevani

- 1. päev :: Tere tulemast :: Inimesed, töökoht ja juurdepääs.
- 1. nädal :: Orienteerumine :: Meeskond, süsteemid ja esimesed ülesanded.
- 30 päeva :: Varjutamine :: Õppige tööd ja konteksti.
- 60 päeva :: Iseseisev :: Korja ja lõpeta ülesanded ise.
- 90 päeva :: Panustamine :: Täiesti rollis.
