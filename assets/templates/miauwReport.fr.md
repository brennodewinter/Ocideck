# 3. Exécution

---

# Activités d'exécution

- Supposons la violation comme point de départ.
- Qualification avec CVSS 4.0 (score + chaîne vectorielle).
- Preuve : hachages de éléments de preuve (SHA1/SHA-256).
- Validation des résultats de l'analyse (pas de confiance aveugle dans le scanner).
- Documenter les chemins d’accès utilisés.
