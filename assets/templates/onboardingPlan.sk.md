# Účel onboardingu

- Rýchlo sa zorientujte v ľuďoch, systémoch a spôsoboch práce
- Jasné, dosiahnuteľné ciele pre každú fázu
- Niekto, kto vám pomôže a na koho sa môžete obrátiť
- Od tieňovania až po nezávislé prispievanie

<!-- _class: timeline -->

# Od prvého dňa po deň 90

- Deň 1 :: Vitajte :: Ľudia, pracovisko a prístup.
- 1. týždeň :: Orientácia :: Tím, systémy a prvé úlohy.
- 30 dní :: Tieňovanie :: Naučte sa prácu a kontext.
- 60 dní :: Nezávislosť :: Zoberte a dokončite úlohy sami.
- 90 dní :: Prispievanie :: Plne v úlohe.
