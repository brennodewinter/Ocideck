# De ce această cutie de instrumente / LMRA

- Chiar înainte de a începe munca, faceți o pauză împreună asupra riscurilor
- Toată lumea știe sarcina, pericolele și controalele
- Oricine poate și trebuie să oprească lucrarea dacă nu este sigură
- LMRA este verificarea finală la fața locului
