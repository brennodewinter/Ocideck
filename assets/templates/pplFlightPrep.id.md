# Pengarahan Penumpang
<!-- ocideck_list_style: checklist -->

- [ ] Sabuk pengaman dan pintu

- [ ] Jangan sentuh kontrolnya
- [ ] Laporkan mual atau ketidaknyamanan segera

- [ ] Ponsel/barang lepas
