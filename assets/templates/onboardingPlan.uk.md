# Мета вступу на борт

- Швидко орієнтуйтеся в людях, системах і способах роботи
- Чіткі, досяжні цілі на етапі
- Той, хто тобі допомагає і до кого ти можеш звернутися
- Від стеження до незалежного внеску

---

<!-- _class: timeline -->

# З 1 дня по 90 день

- День 1 :: Ласкаво просимо :: Люди, робоче місце та доступ.
- Тиждень 1 :: Орієнтація :: Команда, системи та перші завдання.
- 30 днів :: Спостереження :: Вивчіть роботу та контекст.
- 60 днів :: Незалежний :: Самостійно збирай і виконуй завдання.
- 90 днів :: Зробити внесок :: Повністю відповідати ролі.
