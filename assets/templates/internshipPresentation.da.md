# Tilgang i faser

- Uge 1 :: Udforsk :: Lær virksomheden, afdelingen og opgaven at kende.

- Uge 6 :: Udfør :: Bygger, tester og tjekker ind med vejlederen undervejs.
- Uge 10 :: Afslut :: Aflevering, aflevering og færdiggørelse af rapporten.
