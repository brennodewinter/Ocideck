# Iiarbeitigsplan (30-60-90 Täg)
## Neuer Mitarbeiter · Rolle · Leitfaden · Startdatum

---

# Zweck des Onboardings

- Finden Sie sich schnell in Menschen, Systemen und Arbeitsweisen zurecht
- Klare, erreichbare Ziele pro Phase
- Jemand, der Ihnen hilft und an den Sie sich wenden können
- Vom Hospitieren bis zum selbstständigen Mitwirken

---

<!-- _class: timeline -->

# Von Tag 1 bis Tag 90

- Tag 1 :: Willkommen :: Menschen, Arbeitsplatz und Zugang.
- Woche 1 :: Orientierung :: Team, Systeme und erste Aufgaben.
- 30 Tage :: Shadowing :: Lernen Sie die Arbeit und den Kontext kennen.
- 60 Tage :: Selbstständig :: Aufgaben selbst übernehmen und erledigen.
- 90 Tage :: Mitwirken :: In der Rolle voll auf dem Laufenden sein.
